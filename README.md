# directory-search-tool

共有フォルダ・NAS の**フォルダ名・ファイル名を、インストール不要で検索できる HTML 1枚**にするツールです。
「あの資料、どの部署の何年度のフォルダだっけ?」を、NAS を開いて探し回らずに解決します。

- 検索画面は**ただの HTML ファイル**。NAS に置いてダブルクリックするだけ(サーバー・インストール不要)
- 外部通信なし。データは HTML に埋め込まれます
- Windows PowerShell 5.1 だけで動作(追加ソフト不要)

> **注意**: 一覧は作成時点のスナップショットです。追加・削除を反映するには再スキャンが必要です。

## 使い方

### 1. 一覧(検索画面)を作る
1. `検索インデックス作成.bat` をダブルクリック
2. 対象フォルダのパスを貼り付けて Enter(NAS は `\\サーバー名\共有名` 形式)。空のまま Enter でフォルダ選択ダイアログ
3. 保存先フォルダを選択
4. 完了すると、保存先に `検索画面.html` が出力されます

引数でも実行できます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\検索インデックス作成.ps1 -TargetFolder "\\server\share" -OutputDirectory "D:\out"
```

### 2. 配布する
`検索画面.html` を NAS などの共有場所に置き、利用者はダブルクリックで開きます。

## 検索画面の機能
- フォルダ名・ファイル名を対象にしたキーワード検索(パス全体が対象)
- スペース区切りで AND、`-語` で除外
- 全角/半角、大文字/小文字、ひらがな/カタカナの違いを区別しない
- 種類、拡張子、更新年、ファイル名のみ、での絞り込み
- 並び順: 関連順 / 更新日 / 名前 / サイズ
- 結果のフォルダ階層をクリックして、そのフォルダ内に絞り込み
- フルパスのコピー(エクスプローラーのアドレスバーに貼り付けて開く)

## ファイル構成
| ファイル | 役割 |
|---|---|
| `検索インデックス作成.bat` | ダブルクリック用ランチャー |
| `検索インデックス作成.ps1` | スキャナー本体 |
| `検索画面テンプレート.html` | 検索画面の元(`.ps1` と同じフォルダに置く) |

## 運用上の注意
- **権限**: スキャンした人が読めたフォルダ・ファイルの名前がすべて HTML に入ります。HTML を開ける人には全部見えるため、部署ごとに HTML を分ける、HTML 自体にアクセス権を設定する等で管理してください。
- **規模**: 数十万ファイルまでを想定しています。大きすぎると HTML の読み込みが重くなります。その場合は部署別に分けてください。
- **定期更新**: Windows のタスクスケジューラーで再スキャンを定期実行できます(PC が起動していることが必要です)。
- **除外**: ごみ箱、`@eaDir`、`#recycle`、シンボリックリンク、`~$` で始まる一時ファイル、`.tmp .db .ini .sys .lnk .bak` は対象外です。`.ps1` 冒頭の設定で変更できます。

## 文字コードに関する注意
- `.ps1` は **UTF-8 (BOM付き)** で保存してください。BOM がないと PowerShell 5.1 で日本語が文字化けします。
- `.bat` は **Shift-JIS** で保存してください。
